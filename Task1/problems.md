# Аудит мер по обеспечению безопасности данных

---

## **Выявленные проблемы**
### **Хранение данных**
- Данные хранятся в открытом виде (Excel, PDF, JPG) без шифрования.
- Отсутствует централизованное хранилище.
- Нет резервного копирования и аварийного восстановления.

### **Контроль доступа**
- Нет ролевого разграничения (RBAC/ABAC).
- Доступ к файлам через общие папки без аутентификации.
- Отсутствие двухфакторной аутентификации (2FA).

### **Защита информации**
- Персональные, медицинские и финансовые данные не зашифрованы.
- Нет системы предотвращения утечек (DLP).
- Отсутствует классификация данных по чувствительности.

### **Мониторинг и аудит**
- Действия с данными не логируются.
- Нет инструментов анализа угроз (SIEM).
- Не отслеживаются аномальные активности.

### **Регуляторные требования**
- Нет механизма удаления данных по запросу (GDPR/ФЗ-152).
- Не определены сроки хранения данных.
- Риск несоответствия стандартам безопасности.

---

## **Комплексное решение**

### **1. Централизованное хранилище**
- **Миграция данных** в защищенную СУБД с шифрованием.
- **Файловое хранилище** с шифрованием и контролем версий.
- **Резервное копирование**.

### **2. Система контроля доступа**
- Внедрение **RBAC** (роли: врач, бухгалтер, ресепшн).
- Использование **ABAC** для контекстного доступа (например, "только свои пациенты").
- Обязательная **двухфакторная аутентификация**.

### **3. Защита данных**
- **Шифрование** на уровне:
  - Баз данных.
  - Файловых хранилищ.
  - Отдельных полей.
- **Токенизация** платежных данных.
- **Маскирование** данных в отчетах для аналитики.

### **4. Маркировка данных**
- **Тегирование данных** по категориям:
  - `Public` (общедоступные).
  - `Internal` (служебные).
  - `Confidential` (персональные данные).
  - `Strictly Confidential` (медицинские/финансовые).

### **5. Аудит и мониторинг**
- Внедрение **SIEM-систем** для:
  - Логирования всех действий с данными.
  - Генерации оповещений о подозрительных событиях.
  - Анализа угроз в реальном времени.
- Регулярный аудит доступа и политик безопасности.

### **6. Автоматизация процессов**
- Автоматическая классификация данных на основе контента.
- Удаление устаревших данных по политикам ретеншна.
- Интеграция с ERP/CRM для минимизации ручного ввода.

### **7. Обучение и документация**
- Обучение сотрудников:
  - Работа с конфиденциальными данными.
  - Правила использования систем шифрования.
  - Действия при подозрении на утечку.
- Разработка регламентов:
  - Политика безопасности данных.
  - Инструкции по реагированию на инциденты.

---

## **Ожидаемые результаты**
- Соответствие требованиям GDPR и ФЗ-152.
- Снижение риска утечек.
- Автоматизация процессов работы с данными.
- Повышение прозрачности и контролируемости системы.
